# PAC·AGENTS — Pac-Man แบบ Multi-Agent

เกม Pac-Man ที่เขียนด้วย **HTML + CSS + JavaScript ล้วน** ไม่ต้องติดตั้งอะไร ดับเบิลคลิก `index.html` ก็เล่นได้ทันที
ผีทุกตัวเป็น **agent** ที่รับรู้ ตัดสินใจ และ (ถ้าเปิด) ประสานงานกันเป็นทีม

## เล่นยังไง
- เปิด `index.html` ในเบราว์เซอร์ (หรือขึ้น GitHub Pages ตามด้านล่าง)
- ลูกศร / WASD เดิน · `Space` แช่แข็งผี · `P`/`Esc` พัก · `B` เปิด Agent Inspector · `M` ปิดเสียง
- มือถือ: ปัดหน้าจอ หรือใช้ปุ่มลูกศรที่ขึ้นให้

## ฟีเจอร์
| หมวด | รายละเอียด |
|---|---|
| โหมดเล่น | เล่นปกติ · 2 ผู้เล่น (P1 Pac-Man / P2 คุมผี Blinky) · ดู AI เล่นเอง (1×–8×) |
| ความยาก | ง่าย / ปกติ / ยาก / โหด — ต่างกันที่ความเร็วผี ระยะมองเห็น อัตราพลาด ชีวิต เวลาผีกลัว และตัวคูณเหรียญ |
| เหรียญและร้านค้า | เหรียญทองโผล่ในแมพ + เหรียญจากเม็ด/ผี/ผลไม้/ผ่านด่าน/คะแนนจบเกม → ซื้อสกิน Pac-Man (10) สกินผี (6) ธีมแมพ (6) เอฟเฟกต์ทางเดิน (5) อัปเกรดถาวร (ชีวิต/พลัง/ความเร็ว/แม่เหล็กเหรียญ) และไอเทม (โล่/แช่แข็ง) |
| แมพ | คลาสสิก · สุ่มแบบสมมาตร (ใส่ seed ได้) · สร้างเองในตัวแก้ไข |
| ห้องทดลอง | รันจำลองหลายสิบรอบเพื่อเปรียบเทียบ ประสานงาน vs อิสระ, BFS vs A* vs Greedy, จำนวนผี, ระดับความยาก พร้อมค่าเฉลี่ยและช่วงความเชื่อมั่น 95% |
| Agent Inspector | เส้นทางที่ผีวางแผน เป้าหมาย บทบาท จำนวนโหนดที่ขยาย และ Message Board ระหว่างผี |
| เซฟเกม | เก็บใน `localStorage` (เหรียญ สกิน สถิติ แมพที่สร้าง) |

## แนวคิด Multi-Agent ที่ใช้
- **Perception จำกัด:** ผีมองเห็น Pac-Man เฉพาะภายในระยะทางเดิน (ขึ้นกับความยาก) ระดับโหดมองเห็นทั้งแมพ
- **อิสระ (independent):** แต่ละตัวใช้บุคลิกของตัวเอง — Blinky ไล่ตรง, Pinky ดักข้างหน้า, Inky โอบล้อม, Clyde ขี้อาย — ถ้าไม่เห็นจะเดินสุ่ม
- **ประสานงาน (coordinated):** `Team` เป็น blackboard — ผีที่เห็นแจ้งตำแหน่งให้ทุกตัว (`SPOTTED`) แล้วแบ่งบทบาทแบบไดนามิกตามระยะ:
  `HUNTER` ไล่ตรง · `INTERCEPTOR` ดักตำแหน่งข้างหน้า · `FLANKER` อ้อมไปตัดทางหนี · `BLOCKER` ยึดพาวเวอร์/อีกฝั่ง
  ถ้าเสียตำแหน่ง (`LOST`) จะมี `TRACKER` ตามจุดล่าสุด ที่เหลือ `SWEEP` กวาดโซนที่ยังมีเม็ดเยอะ
- **Pac-Man AI:** BFS หาเป้า (เม็ด/พาวเวอร์/ผลไม้/เหรียญ/ผีที่กลัว) เฉพาะช่องที่ไปถึงก่อนผี ถ้าไม่มีทางปลอดภัยจะหนีไปทางที่ไกลผีที่สุด

## ขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (`index.html`, `css/`, `js/`, `README.md`)
2. ไปที่ **Settings → Pages**
3. ที่ **Source** เลือก *Deploy from a branch* → branch `main` → โฟลเดอร์ `/ (root)` → Save
4. รอประมาณ 1 นาที จะได้ลิงก์ `https://<username>.github.io/<repo>/`

## ทดสอบด้วยตัวเอง
เปิดคอนโซลเบราว์เซอร์แล้วรันได้เลย เช่น

```js
PM.runTrial({ difficulty: 'normal', coordination: true, algo: 'astar', ghostCount: 4, seed: 1, cap: 90 })
```

❓ วิธีเล่น

🎮 ควบคุม

  • เดิน: ลูกศร หรือ WASD (มือถือ: ปัดหน้าจอ / ปุ่มลูกศร)
  • Space: แช่แข็งผี 4 วินาที (ต้องซื้อไอเทมก่อน)
  • P / Esc: พักเกม   B: เปิด Agent Inspector   M: ปิดเสียง
  • 2 ผู้เล่น: P1 ใช้ WASD คุม Pac-Man, P2 ใช้ลูกศรคุมผี Blinky

💰 เหรียญและร้านค้า

  • เหรียญทองที่โผล่ในแมพ = 1–3 เหรียญ (หายไปใน 11 วินาที)
  • กินเม็ดครบทุก 25 เม็ด, กินผี, ผลไม้, ผ่านด่าน และคะแนนตอนจบ → ได้เหรียญ
  • ยิ่งยากยิ่งได้เหรียญคูณ (ง่าย ×0.6 → โหด ×2.5)
  • เอาไปซื้อสกิน Pac-Man / ผี / ธีมแมพ / เอฟเฟกต์ / อัปเกรดถาวร / ไอเทม

👻 ผีเป็น Agent

  • Blinky ไล่ตรงๆ · Pinky ดักข้างหน้า · Inky โอบล้อม · Clyde ขี้อาย
  • เปิด ประสานงาน: ผีแชร์ตำแหน่ง Pac-Man แล้วแบ่งบทบาท HUNTER / INTERCEPTOR / FLANKER / BLOCKER เป็นไดนามิก ถ้าหาไม่เจอจะกระจายกันกวาดพื้นที่
  • เปิด Agent Inspector (ปุ่ม 🧠) เพื่อดูเส้นทาง เป้าหมาย บทบาท และข้อความระหว่างผีแบบเรียลไทม์
  • กิน พาวเวอร์ เพื่อให้ผีกลัวแล้วกลับไปกิน (คะแนนคูณ ×2 ต่อตัว)

🧪 โหมดพิเศษ

  • ดู AI เล่นเอง: Pac-Man ตัดสินใจเองว่าจะเก็บอะไร หนีอะไร ปรับความเร็วได้ถึง 8×
  • ห้องทดลอง: รันการจำลองจำนวนมากเพื่อเปรียบเทียบทีมผีแบบต่างๆ
  • สร้างแมพ: วาดเขาวงกตเอง หรือสุ่มแมพสมมาตร แล้วเล่นได้ทันที
